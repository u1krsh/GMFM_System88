MotorMeasure Pro (GMFM-88)

Digitizing Gross Motor Function Measure Clinical Workflows
1Abstract
MotorMeasure Pro is a clinical assessment application that digitizes the GMFM-88 scoring process. It replaces paper-based scoresheets with a mobile-first digital workflow supporting 88 items across 5 motor domains, with offline-first cloud sync architecture.
Architecture
Views Layer
Flet UI — Dashboard, Scoring, Settings
Events & Updates
Services Layer
Auth, Sync, Report & Scoring Engine
Read & Write
Data Layer
SQLite DB & Pydantic Models
60s Background Sync
Cloud Backend
Supabase PostgreSQL + RLS
2Design Objectives
  • Digitize clinical workflows intuitively
  • Cross-platform native (Android, iOS, Desktop)
  • Offline-first resiliency with local processing
  • Enterprise-level encrypted data protection
  • Automated intelligent cloud synchronization
4Prototype Design
  • Built with Python 3.11 and Flet framework
  • Three-tier PDF fallback generation system
  • Hardware-optimized haptics and UI scaling
  • Zero-dependency deploy with embedded assets
5Working Model
  • Git-like sync logs writes to a local queue
  • Background worker pushes/pulls every 60s
  • Dual Auth: PBKDF2 Local + Supabase Cloud
  • Automated score computation and charting
6Advantages
  • Clinical-grade auto-generated PDF reports
  • Operates flawlessly offline in remote areas
  • Fernet encryption-at-rest for patient privacy
  • Rapid legacy DOCX assessment imports
7Applications
  • Pediatric Physiotherapy clinics worldwide
  • Longitudinal clinical mobility research trials
  • Remote tele-rehabilitation monitoring
  • Special education disability evaluations
